1.3 Hook helper hooks/useNotify.ts (NOU)
export function useNotify() {
  const { showNotification } = useNotificationBanner();
  return {
    success: (title: string, message?: string) => showNotification({ type:'success', title, message, icon:'CheckCircle' }),
    info:    (title: string, message?: string) => showNotification({ type:'info', title, message, icon:'Info' }),
    warning: (title: string, message?: string) => showNotification({ type:'warning', title, message, icon:'AlertTriangle' }),
    error:   (title: string, message?: string) => showNotification({ type:'error', title, message, icon:'XCircle' }),
    reward:  (title: string, message?: string) => showNotification({ type:'reward', title, message, icon:'Trophy' }),
  };
}

Persistență: Supabase tabel gamificare (recomandat) SAU AsyncStorage gamificare_v1 fallback. La login: citește din Supabase → cache AsyncStorage.

4.2 Formula de nivel (curbă tip joc video)
xpNecesarPanaLaNivel(n) = 100 * n * (n + 1) / 2 (cost cumulativ crescător). Din xpTotal derivă nivelul + XP în nivel + XP până la următorul.
Titluri: 1-4 Începător · 5-9 Atlet · 10-14 Războinic · 15-19 Elită · 20+ Legendă.

4.3 Generarea obiectivului zilnic minim
La prima deschidere din zi (ultimaZiActiva != azi): resetează questuriAzi cu 3 quest-uri:
{ tip:'minute_miscare', tinta:15, xp:50, descriere:'Fă minim 15 min de mișcare' }
{ tip:'antrenamente', tinta:1, xp:60, descriere:'Completează 1 antrenament' }
{ tip:'proteine', tinta:<ținta proteine din profil>, xp:40, descriere:'Atinge ținta de proteine' }

"Minimul zilnic" = completarea celor 3 quest-uri. E cerința de bază, ca într-un joc.

4.4 Logica de streak
Dacă obiectivul zilnic e completat integral → la trecerea în ziua următoare, dacă ieri a fost completat: streak += 1; altfel streak = 0.
Zi sărită complet → streak = 0.
Milestones: 3, 7, 14, 30, 100 zile → insignă + reward notification.

4.5 Acordare XP & update progres
adaugaProgres(tip: QuestZilnic['tip'], valoare: number): void
Crește progresul quest-ului; dacă atinge ținta și nu era completat: completat=true, xpTotal += quest.xp, notify.reward('Quest completat!','+XP'), verifică level-up. Level-up → notify.reward('Nivel nou!','Ai ajuns Nivel X') + animație header.
Apeluri: salvare antrenament → adaugaProgres('antrenamente',1) + ('minute_miscare',durata) + ('calorii_arse',kcal); salvare masă → adaugaProgres('proteine',proteineMasa).

4.6 Insigne — constants/insigne.ts (NOU)
id, nume, descriere, icon, condiție. Ex: prima_transpiratie (primul antrenament), streak_7, streak_30, forta_bruta (50 antrenamente forță), maratonist (100 min cardio/zi). Secțiune insigne în profil.tsx: grid câștigate (color) vs blocate (gri).

4.7 UI de recompensă
La completarea obiectivului zilnic complet → overlay "Obiectiv zilnic completat!" cu XP câștigat + streak + buton "Continuă", confetti + haptic. Pentru evenimente mici, reutilizează notificarea type='reward' (AGENT 1).

create table gamificare (
